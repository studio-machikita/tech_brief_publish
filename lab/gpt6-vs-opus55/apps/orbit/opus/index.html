3D表示を開始できません

このブラウザまたは端末では WebGL2 が利用できないため、Orbit Lab を表示できません。

  • 最新版の Chrome / Edge / Firefox / Safari をお試しください。
  • ブラウザ設定で「ハードウェアアクセラレーション」が有効か確認してください。
  • リモートデスクトップや仮想環境では GPU が使えない場合があります。

プログラムを読み込めませんでした

ページをローカルサーバー経由で開いているか、npm install を実行済みか確認してください（README 参照）。
