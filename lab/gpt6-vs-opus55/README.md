# Tech News Radio Lab — 4モデル・8作品の比較サイト

GPT-6 Astra / Sol / Luna、Claude Opus 5.5が制作した **Orbit Lab** と **Sales Lens** を比較する静的サイトです。

## ページ構成

- `assets/measurements.json`：Orbit Lab / Sales Lensの実測データ。
- `index.html`：Orbit Lab / Sales Lensの8作品を操作する比較ページ。


## 開き方

このフォルダーで次を実行し、ブラウザーで `http://127.0.0.1:8088/` を開きます。

```powershell
python -m http.server 8088 --bind 127.0.0.1
```

ES Modulesを使うため、`index.html` のダブルクリックではなくHTTPで配信してください。

## 公開方法

配信用ZIPを展開したフォルダーの中身を、そのまま静的ホスティングにアップロードできます。ビルド、サーバー処理、APIキーは不要です。サブディレクトリーへの配置にも対応します。

## できること

- 4作品のスクリーンショット一覧と拡大表示
- 1作品の操作、2作品を並べたライブ比較
- 1440px / 390pxの画面幅の切り替え
- トークン、所要時間、応答回数、API料金換算の比較
- 実測データのJSONダウンロード、考察・比較条件の確認
- URLに選択状態を保存して比較画面を共有

## 収録内容と留意点

2026年9月23日の各1回の実験結果です。品質の問題も比較対象なので、元作品の不具合は修正していません。静的配信に必要な読み込み先とLunaのCSS読み込みのみ調整しています。変更記録は `distribution-manifest.json` を参照してください。

Three.js 0.186.0とライセンスは `vendor/three/` に同梱しています。元作品のGoogle Fonts指定は維持しており、ネットワーク未接続時は代替フォントで表示します。作品や計算の実行に外部サービスへの接続は不要です。

トークンはキャッシュ込み総入力＋出力、料金は通常API価格での参考換算です。月額プランの実請求額ではありません。円換算は1ドル＝150円の仮定です。モデルごとに実行アプリ・ツール・トークンの数え方が違うため、純粋なモデル性能の順位ではありません。

生の実行ログ、アカウント情報、セッションID、認証情報は収録していません。作品内のCSVは利用者のブラウザー内で処理されます。

## 地球フォーカスの追加画面

作品比較ページのOrbit Labには、4作品をリセット・停止して標準の地球フォーカスを操作した追加キャプチャを掲載しています。作品ごとのカメラ位置や倍率を維持し、元作品の不具合も補正していません。撮影条件は `assets/earth-captures.json` に収録しています。

比較ページの冒頭に4モデルの結論を掲載しています。料金とトークンは同じカードで切り替え、通常は料金を表示します。時間は独立したカードに常時表示します（URLでトークンを明示した場合はその選択を復元）。

## 投入プロンプトと費用比

課題ごとのプロンプトを開いて読めるように掲載し、TXTと共通CSVを `assets/prompts/` に同梱しています。Sales LensのGPT-6版・Opus版は別々に収録。個人のローカルパスは記号に置換し、改行をLFに統一しています。掲載内容のハッシュと変更範囲は同フォルダーの `manifest.json` を参照してください。

冒頭の費用比は中量級・重量級の2課題合計に限定したAPI料金換算です。根拠の合計と比率は `assets/cost-summary.json` にあります。
